# flash-attn source build.

# API (cache.layers, layer_cache.keys) from the 5.x cache refactor; the older
# key_cache/value_cache layout (<=4.51) crashes with "'DynamicCache' object has no
# attribute 'layers'".  The flash_attention_2 .pth patch also targets 5.x's
# get_correct_attn_implementation().  Do not loosen this without re-testing both.
